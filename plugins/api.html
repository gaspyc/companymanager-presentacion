Escribir el código

Un plugin de importación es una clase de Python que recibe la ruta de un archivo y devuelve dos listas: los productos y sus precios. El sistema se encarga del resto: mostrarlos, dejar que se revisen y guardarlos.

Entra un archivoEl PDF, Excel o CSV que el comercio sube en "Importar con motor".
Tu clase lo leeextract(ruta) devuelve {"products": [...], "prices": [...]}.
Sale una vista previaEl catálogo muestra las filas para revisar antes de confirmar.

adapter.py

Un ejemplo completo: leer un CSV de proveedor

import csv from companymanager.adapters.base import ( AdapterCapabilities, AdapterMetadata, BaseAdapter, ) class LectorNorte(BaseAdapter): metadata = AdapterMetadata( name="Lector de listas Distribuidora Norte", version="1.2.0", type="csv", capabilities=AdapterCapabilities(products=True, pricing=True), role="extractor", ) def _filas(self, ruta): with open(ruta, encoding="utf-8") as archivo: # leer no pide permiso return list(csv.DictReader(archivo, delimiter=";")) def extract_products(self, ruta): return [ {"sku": f["Codigo"], "name": f["Articulo"], "brand": f["Marca"], "category": f["Rubro"]} for f in self._filas(ruta) ] def extract_prices(self, ruta): precios = [] for f in self._filas(ruta): precios.append({"sku": f["Codigo"], "min_quantity": 1, "amount": float(f["Precio"])}) if f.get("PrecioBulto"): # una escala por bulto precios.append({"sku": f["Codigo"], "min_quantity": int(f["Bulto"]), "amount": float(f["PrecioBulto"])}) return precios
La clase hereda de BaseAdapter y su nombre es el main_class del manifest. Si no hereda, el plugin no se carga.
capabilities dice qué devuelve: con products=True se llama a extract_products, con pricing=True a extract_prices. Lo que declares y no implementes falla.
Los precios se unen a los productos por SKU. Varias filas con distinto min_quantity son escalas por cantidad.
El id del plugin lo pone el sistema: siempre es el unique_slug del manifest, aunque la clase diga otra cosa.

Cada productosku y name son los que importan. Opcionales: brand, category, taxonomy_type, line, base_unit, allows_decimal, purchase_unit, purchase_to_base_factor, is_active.
Cada preciosku, amount y min_quantity (también se acepta min_qty). currency es opcional: sin ella se usa la moneda de la sede.

Cómo corre

En un proceso aparte, con el archivo y nada más

25 segundosSi el plugin no termina en ese tiempo, se corta y el comercio ve "No se pudo procesar el archivo de catalogo.".
Solo vuelve lo que devolvésEl resultado viaja como JSON: tiene que ser serializable (textos, números, listas y diccionarios). Lo que imprimas no se muestra al comercio.
Sin las credenciales del sistemaEl proceso arranca con un entorno recortado: no hereda contraseñas ni claves de la app. Lo que necesites conectar, lo trae tu código.
Un error no rompe nadaSi tu código lanza una excepción, la importación se cancela y el catálogo queda como estaba. El detalle queda en el registro de la plataforma.

Más allá de importar

Otras interfaces, todavía no abiertas a la comunidad

En pruebaPlugins de preciosUna clase que hereda de BasePricingAdapter e implementa calculate_raw_prices(business_id, cart_items, store): recibe el carrito y devuelve los precios. Así funciona Mix & Match. Uno de la comunidad corre aislado solo si la plataforma lo habilita.
En el planEventos del sistemaQue un plugin reaccione a una venta, a un cambio de stock o a un pedido nuevo. Hoy no existe una interfaz de eventos para plugins.
