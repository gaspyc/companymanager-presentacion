Para publicar

Armar el paquete

Un plugin se entrega como un archivo .zip con dos archivos obligatorios en la raíz: manifest.json, que dice quién es y qué pide, y adapter.py, que tiene el código.

manifest.jsonEl nombre, la versión, la clase principal, los permisos y cómo se muestra en la tienda.
adapter.pyUna clase de Python que hereda de BaseAdapter y hace el trabajo.
mi-plugin.zipSe sube desde "Mis publicaciones" en la tienda de plugins.

El ZIP

Qué va adentro, y qué no se acepta

lector-norte.zip
├── manifest.jsonobligatorio
├── adapter.pyobligatorio
├── columnas.pytus módulos
└── assets/
    ├── icon.pngopcional
    └── banner.pngopcional
Límites de tamañoEl ZIP hasta 8 MB, descomprimido hasta 32 MB, cada archivo hasta 8 MB y como máximo 256 archivos. Un archivo que se comprime más de 100 veces se toma como sospechoso.
Lo que se rechaza siempreEnlaces simbólicos, archivos cifrados, rutas absolutas o con .., y dos archivos con el mismo nombre (sin importar mayúsculas).
Ícono y bannerSe declaran en assets y tienen que estar en el ZIP. Sin ellos, la tienda usa una imagen por defecto.

El manifest.json

Cuatro campos obligatorios; el resto mejora la ficha

CampoQué es
unique_slugEl identificador del plugin en toda la plataforma. Letras, números, puntos, guiones y guiones bajos; empieza con letra o número. No se puede reusar el de otro.
name · versionEl nombre que se ve en la tienda y la versión, por ejemplo "1.2.0".
main_classEl nombre de la clase de adapter.py que hereda de BaseAdapter.
permissionsUna lista con lo que el código necesita: read_files, write_files, network, database. Vacía si no necesita nada.
description · authorLo que se lee en "Panorama general". Sin autor, se usa el nombre de tu cuenta.
category · roleCómo se agrupa en la tienda. Las categorías del filtro son adapter, pricing, sales y automation.
price · currency · is_subscriptionEl precio que se muestra. Hoy es informativo: ver Precio y cobro.
access_mode · allowed_user_idsQuién lo puede ver: public, allowlist (solo esas cuentas) o admin_only.
support_email · support_url · docs_url · changelog_urlLos "Recursos del desarrollador" de la ficha.
assets{"icon": "assets/icon.png", "banner": "assets/banner.png"}

Antes de subirlo

Probá tu manifest con las mismas reglas del servidor

Editá el JSON o sacá archivos del ZIP: el veredicto usa los mismos chequeos, en el mismo orden.

Si el ZIP no pasa, la tienda muestra el mismo motivo que ves acá, palabra por palabra. Hay dos más que este simulador no prueba: "El archivo no es un ZIP válido o está dañado." y "El archivo adapter.py tiene un error de sintaxis en la línea N." El mensaje general "No se pudo validar el ZIP del plugin." queda solo para fallas del servidor.

Lo que conviene saber

Detalles que ahorran un rechazo

El slug es para siempreCon un slug publicado no se puede subir otra propuesta: una versión nueva se pide como actualización administrada. Elegí uno con un prefijo tuyo, como tunombre.lector_norte.
Pedí solo lo que usásSi el código importa algo de red o de base de datos sin declarar el permiso, se rechaza. Si declarás un permiso que no usás, se ve en la ficha y el comercio lo lee.
Podés repartir el códigoAdemás de adapter.py podés incluir otros .py e importarlos: la carpeta del plugin se agrega al camino de imports. Todos pasan por el mismo control de seguridad.
Cómo se elige "Auto"Cuando hay varias versiones de un plugin, "Auto" toma la mayor comparándolas como texto. Mantené el mismo formato en todas (1.2.0, 1.3.0) para que el orden sea el esperado.
